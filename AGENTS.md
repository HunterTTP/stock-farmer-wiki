# Working in this checkout

The public player wiki. Pages are in `src/content/docs/`; `src/data/` and `public/sprites/` are generated from the game's catalogs and never edited by hand.

- Never commit, push or publish here: page drafts stay uncommitted until the game repo's publish script commits and deploys them with a beta release.
- Never type a number that a data table owns. Write in the style guide's player words (`docs/WIKI.md` in the iPhone game's checkout beside this one).
- Shared agent rules: `agents/README.md` in the private research checkout beside this one. List the pages you changed when you hand back.
